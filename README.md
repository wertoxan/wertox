# Petrick Engineering Portfolio

Selected offline examples from personal projects. These are curated demonstration copies, not production deployments. Data is fictional. No external services, accounts or credentials required.

| Example | What to inspect |
| --- | --- |
| [Yoru — catalog](yoru-site/) | Episode-number normalization with configurable rules and tests. |
| [Yoru — Mini App](yoru-bot/) | Back-button navigation in a testable local shell; not a deployable Telegram bot. |
| [SIGNAL](signal/) | Classification, filters and reply drafts for synthetic job postings; no Telegram API. |
| [Content Factory](content-factory/) | Template-based content generation and local moderation examples; no external AI service. |
| [Event outbox](event-outbox/) | Payment-event validation, idempotency and retries against synthetic orders. |
| [Frontend demos](frontend-demos/) | Three interactive landing-page concepts from the portfolio site, with local forms. |

Each folder has setup notes. The repos [Illustration Composer](https://github.com/wertoxan/illustration-composer) and [Speedtest](https://github.com/wertoxan/speedtest) are separate examples.

This repository does not include production data, deployment configuration, the original archives or their Git history.
