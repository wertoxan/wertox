# Yoru catalog | portfolio excerpt

An offline extract of the release-number normalization logic developed for Yoru's catalog. A known continuous episode sequence can be presented as season-local numbering without losing the source numbering. The rule applies only on an exact identity match and a complete, unique, in-range sequence.

The sample and identifiers are fictional. This is not the live site: no provider clients, streams, media, catalog dumps, user data, deployment configuration, or credentials are included.

Run the local examples and checks with Node.js: `node --test`.
